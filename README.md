## Sobre

O **SecToolkit** é um repositório de scripts e ferramentas voltados ao estudo e à prática de cibersegurança, automação e administração de sistemas.

As ferramentas são organizadas por finalidade, independentemente da linguagem de programação utilizada.

## Explore the Toolkit

| Categoria | Descrição |
|---|---|
| [Recon](./recon/) | Reconhecimento, DNS, WHOIS e coleta de informações públicas. |
| [Web](./web/) | Análise de aplicações web e inspeção de cabeçalhos HTTP. |
| [Network](./network/) | Redes, portas, serviços e protocolos. |
| [System](./system/) | Administração de sistemas, hashes e verificações locais. |
| [Forensics](./forensics/) | Análise de arquivos e artefatos digitais. |
| [Utils](./utils/) | Utilitários gerais, automação e geração de senhas. |

## Como utilizar

```bash
git clone https://github.com/paulemacedo/sectoolkit.git
cd sectoolkit
```

Acesse a categoria desejada e consulte a documentação de cada ferramenta para verificar seus requisitos e instruções de uso.

## Aviso legal

Este repositório tem finalidade educacional, de pesquisa e de uso autorizado em cibersegurança. Utilize as ferramentas apenas em sistemas próprios ou em ambientes nos quais você tenha autorização para realizar testes.
